### Download

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1 and newer) | **SkipMan-mac-apple-silicon.zip** |
| Mac with Intel | SkipMan-mac-intel.zip (if listed) |
| Windows 10 / 11 | **SkipMan-windows.zip** |

**Mac:** unzip, drag **SkipMan** into Applications, open it. Because SkipMan
isn't from the App Store, macOS blocks the first launch. Go to
System Settings → Privacy & Security, click **Open Anyway**, and confirm. The
first time you send a song, click **OK** when SkipMan asks to control Music.

**Windows:** unzip anywhere (e.g. Documents\SkipMan) and run **SkipMan.exe**.
If SmartScreen appears, click **More info → Run anyway**. Apple Music for
Windows must be installed and opened once.

Already have SkipMan? It updates itself. Look for the RESTART button.
